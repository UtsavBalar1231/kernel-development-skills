For videos, pages, and other visual work, avoid the stock AI aesthetic: dark gradient backgrounds with blurred color blobs, dot grids, glassy pill badges, glowing highlights, gradient or per-letter animated titles, bouncy spring pop-ins, and the default Inter plus macOS traffic-light window look. Prefer one concept tied to the product and executed with restraint: few elements, each with a job, one accent color used only for annotation, ease-out motion, hard cuts.

**Why:** the user rejected a polished dark motion-graphics walkthrough as "AI generated slop" and accepted a printed-field-guide design (flat paper page, serif headings, the real terminal as a captioned figure, numbered margin notes) on 2026-10-12. They also want real material over reconstructions: real terminal sessions, not summary cards.

**How to apply:** before building visuals, pick a concept from the product itself, build one style frame, and check every element for a job before propagating. Show real artifacts (terminal recordings, actual output) rather than designed summaries of them. Related: [[project-publishing-channels]], [[feedback-kernel-skill-voice]]
